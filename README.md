## 🌟 Project Overview

**AI Toolbox** is a hand-curated, zero-build-step directory of **880+ AI tools** across **34 categories**. It runs entirely in your browser — no server, no database, no login. Add the four files to any static host (GitHub Pages, Netlify, Vercel, S3) and you're live in under a minute.

Every tool is tagged with a **category** and a **price tier** (Free / Free plan / Paid), so users can filter down to exactly what they need — whether that's "free image generators," "paid legal AI," or "coding agents that start free."

### 🎯 Problem Statement

Finding an AI tool shouldn't require wading through sponsored placements, popups, and 10,000-row directories that list every model version as a separate product. AI Toolbox takes the opposite approach:

- **Hand-curated** — every tool is a real, established product
- **Price-honest** — a clear free / freemium / paid tag on every card
- **Zero-signup** — no account, no tracking, no cookie wall
- **Filterable in 2 clicks** — search + category + price, all client-side

## ✨ Features

<details>
<summary><b>🔍 Search & Filtering</b></summary>

- **Fuzzy search** across tool name, description, category name, and domain
- Match highlighting on card titles and descriptions
- **Debounced input** (120 ms) for smooth typing on big lists
- Keyboard shortcuts — press `/` to focus search, `Escape` to clear

</details>

<details>
<summary><b>🏷️ 34 Categories</b></summary>

- Chat, research, writing, images, video, voice, music, design, 3D, slides, apps, coding, build/API, automation, email, marketing, social, SEO, sales, support, ecommerce, data, education, careers, finance, legal, translation, **home**, **travel**, **lifestyle**, **accessibility**, productivity, learning, utilities
- Category icons and per-category tool counts on the tile grid
- Selecting a category from the grid scrolls you straight to the filtered results

</details>

<details>
<summary><b>💰 Price Filtering</b></summary>

Three tiers with clear badges on every card:

| Price | Badge Color | Meaning |
|---|---|---|
| `free` | Green | Completely free, no paid tier |
| `freemium` | Indigo | Free plan + optional paid upgrades |
| `paid` | Amber | Paid only (may include trial) |

- Filter by any tier with one click
- The hero stats show "Free to start" — the count of tools with any free option

</details>

<details>
<summary><b>❤️ Saved Favorites</b></summary>

- Bookmark any tool with the heart button on the card
- Saved list persists across page reloads via `localStorage`
- Toggle the "Saved" button in the nav to filter down to bookmarks only
- Saved count is always visible in the nav

</details>

<details>
<summary><b>🌓 Dark Mode</b></summary>

- **Auto-detects** your system preference on first visit (`prefers-color-scheme`)
- **Manual toggle** in the nav — your choice is saved to `localStorage`
- Theme is applied *before paint* (no flash of unstyled content)
- Full CSS variable theming — every color adapts

</details>

<details>
<summary><b>⚡ Performance & UX</b></summary>

- **Zero build step** — pure HTML, CSS, JS
- **Zero dependencies** — no npm, no bundler, no framework
- Favicons lazy-loaded from Google's S2 service with a **graceful letter fallback** (colored initial) when the favicon is unavailable or too small
- Pagination with "Show more" — 32 tools per page
- Animated card entrance (respects `prefers-reduced-motion`)
- Sticky toolbar with shadow-on-scroll effect
- Fully responsive down to 320 px wide

</details>

## 🏗️ Architecture

### 🗂️ Project Structure

```plaintext
ai-toolbox/
│
├── 📄 index.html      # The page — hero, filters, grid, footer, CTA
├── 📄 style.css       # All styles — theme, responsive, animations
├── 📄 script.js       # Logic — search, filter, sort, save, theme
├── 📄 tools.js        # Data — 880+ tools, 34 categories
├── 📄 README.md       # This file
└── 📄 LICENSE         # MIT
```

### 🔄 Data Flow

```plaintext
User action (types / clicks / saves)
        │
        ▼
script.js::filtered()
        ├── Reads TOOLS[] from tools.js
        ├── Filters by: query · category · price · saved
        ├── Sorts: recommended | A–Z
        └── Paginates: 32 per page
        │
        ▼
script.js::renderTools()
        ├── Builds card HTML
        ├── Injects into #tool-grid
        └── Wires favicon fallbacks
        │
        ▼
Browser renders the filtered cards
```

### 🧩 File Responsibilities

| File | Responsibility |
|---|---|
| `tools.js` | The single source of truth — `CATEGORIES[]` and `TOOLS[]` arrays |
| `script.js` | All interactivity — search, filter, sort, save, theme, pagination |
| `style.css` | Full visual system — theme variables, components, responsive breakpoints |
| `index.html` | Static shell — hero, filter controls, grid container, footer |

## 🚀 Quick Start

### 📋 Prerequisites

```plaintext
✓ Any modern browser  (Chrome, Firefox, Safari, Edge)
✓ Optional: Node.js 18+  (only if you want to serve locally)
✓ That's it. Seriously.
```

### 1️⃣ Clone

```bash
git clone https://github.com/darkwebnew/ai-toolbox.git
cd ai-toolbox
```

### 2️⃣ Open It

**Option A** — just double-click `index.html`. It works offline.

**Option B** — serve locally (recommended for dev):

```bash
# With Python (built-in on Mac/Linux)
python3 -m http.server 8000

# Or with Node
npx serve .

# Or with any other static server
```

Then open <http://localhost:8000>.

## 📚 Adding Tools

Every tool lives in `tools.js` as a single `t(...)` line. Open the file and add your tool to the `TOOLS` array:

```js
t("Tool Name", "https://example.com/", "One-line description", "image", "freemium"),
```

| Argument | Example | Notes |
|---|---|---|
| Name | `"Ideogram"` | Displayed title |
| URL | `"https://ideogram.ai/"` | Must be the full URL |
| Description | `"Images with readable text"` | ~3–8 words |
| Category | `"image"` | Must be an existing category id |
| Price | `"freemium"` | `free` / `freemium` / `paid` |

### Adding a New Category

1. Add a `{ id, name }` entry to the `CATEGORIES` array:

```js
{ id: "audiobooks", name: "Audiobooks" },
```

2. Add a matching icon to `CAT_ICONS` in `script.js`:

```js
audiobooks: "📖",
```

3. Reload — your category will appear in the tile grid, category dropdown, and directory header.

## 🚢 Deploy to GitHub Pages

1. Create a new **public** repository on GitHub — `darkwebnew/ai-toolbox` or any name you like.
2. Upload these five files to the **root** of the repo (not in a subfolder):
   - `index.html`
   - `style.css`
   - `script.js`
   - `tools.js`
   - `README.md`
3. Go to **Settings → Pages**.
4. Set **Source** to **Deploy from a branch**.
5. Pick branch `main` and folder `/ (root)`. Click **Save**.
6. Wait ~30 seconds. Your site is live at:

```plaintext
https://darkwebnew.github.io/ai-toolbox/
```

> ⚠️ If your repo is named something else, the URL becomes `https://darkwebnew.github.io/<repo-name>/`.

## 🎨 Customization

### Change the accent color

In `style.css`, edit the `--accent` and `--accent-2` variables at the top:

```css
:root {
  --accent:   #4f46e5;
  --accent-2: #7c3aed;
}
```

Both light and dark blocks need updating if you want a consistent theme.

### Change the popular picks

In `script.js`, edit the `POPULAR` array:

```js
const POPULAR = ["ChatGPT", "Claude", "Gemini", "DeepSeek", "Perplexity", /* … */];
```

Only the first 8 are shown.

### Change the tools per page

```js
const PAGE_SIZE = 32;  // → change to any number
```
